💡 如何获取 CloudBase 环境 ID？
1. 打开 腾讯云 CloudBase 控制台，用微信扫码/QQ 登录
2. 按提示开通一个免费环境，记下页面上的「环境 ID」（形如 my-notes-xxxx）
3. 在「环境配置 → 安全配置 → Web 安全域名」添加本站域名
4. 在「环境配置 → 登录方式」开启「用户名密码登录」
5. 把环境 ID 填入上方输入框，即可注册账号实现多端同步
